# Restore Payment

Secure payment page for **Restore**.

The repository name is `restorecarlos` because this project is the pay code for Restore.

## Stack

- React
- Vite
- Tailwind CSS
- TypeScript
- Stripe

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/restorecarlos.git
cd restorecarlos
npm install
npm run dev
```

The dev server opens at http://localhost:5173.
